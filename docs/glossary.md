# Glossary

| Term | Definition |
|------|------------|
| **Enterprise Brain** | The product: AI-powered organizational memory platform |
| **Cognexus** | Repository / working project name for Enterprise Brain |
| **Knowledge Graph** | Typed nodes and edges representing organizational entities and relationships |
| **Vector Database** | Store of embeddings for semantic similarity search |
| **Chunk** | Segment of text indexed for retrieval |
| **Provenance** | Traceability from derived knowledge back to source artifacts |
| **Grounding** | Constraining AI answers to retrieved evidence |
| **ACL** | Access control list governing who may see an artifact |
| **RBAC** | Role-based access control |
| **ABAC** | Attribute-based access control |
| **Decision Intelligence** | Module for recording and querying organizational decisions |
| **Meeting Memory** | Module for transcripts, summaries, actions, and decisions from meetings |
| **Expertise Discovery** | Ranking people by demonstrated knowledge signals |
| **Knowledge Freshness** | Scoring how up-to-date and trustworthy knowledge is |
| **Reasoning Engine** | Component that plans retrieval and synthesizes answers |
| **Connector** | Integration that syncs an external system into the pipeline |
| **Tenant** | Isolated customer organization in multi-tenant deployments |
| **Air-gapped** | Deployment with no external network connectivity |
